Working in the studio

Good habits for shared machines

The studio computers return to a clean state when they restart. That keeps every station working the same way for every class, and it means your files are only safe once they're somewhere you control.

  1. Save to your own drive or cloud storage, never just the desktop.
  2. In Ableton Live, use File › Collect All and Save before you submit or leave.
  3. No sound? Check that your Mac's output is set to the Scarlett interface.
  4. Don't install software or change system settings. Ask instead.
  5. Coil cables and leave the station ready for the next person.
  6. Report anything broken to Professor Chandler or a work-study student.
